# 3-minute judge demo

## 1. Open the kiosk
Start `frontend/kiosk-app` with a local HTTP server.

## 2. Enter the Tamil example
`என்னோட மாடு காணாமல் போயிருச்சு. யார்கிட்ட புகார் கொடுக்கணும்?`

## 3. Explain the workflow
Show that the intended production flow is:
voice -> understanding -> verified retrieval -> safe guidance -> human escalation.

## 4. Show the repository
Open:
- README
- architecture
- sample case
- safety rules
- tests
- license

## 5. Explain the key distinction
This is not a free-form chatbot. The legal knowledge base and human escalation workflow are the control layer.
