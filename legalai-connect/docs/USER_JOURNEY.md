# Citizen User Journey

1. Citizen enters the private kiosk.
2. Selects Tamil or another available language.
3. Speaks naturally.
4. System confirms the main facts.
5. System asks only necessary follow-up questions.
6. System retrieves relevant approved information.
7. Citizen receives a simple next-step explanation.
8. Citizen can request human assistance.
9. A case reference is created for supported escalation.
10. The citizen leaves with the next step clearly understood.
